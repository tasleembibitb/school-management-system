About this system

This is a demo project. It shows how a degree college in Sukkur could keep its programs, students, attendance, fees and results in one place — starting simple, then adding one feature at a time.

📅 Phase 1 — Done

Landing page and programs list (FSc, FA, ADS, BS, BSc). Responsive layout, mobile menu, program search.

👤 Phase 2 — Next

Student records — add a student and search students by name or program.

✅ Phase 3 — Planned

Attendance — mark students present or absent, day by day.

💳 Phase 4 — Planned

Fees record — track which fees are paid and which are pending.

📊 Phase 5 — Planned

Result report — marks and grades for each program.

🎓 Who built it

Tasleem Bibi, final-year BSCS student, Begum Nusrat Bhutto Women University, Sukkur. PITP Certified Web Developer & Data Scientist. She studied ADS Science at this college.
