About this system

This is a demo project. It shows how a degree college in Sukkur could keep its programs, students, attendance, fees and results in one place — starting simple, then adding one feature at a time.

📅 Phase 1 — Done

Landing page and programs list (FSc, FA, ADS, BS, BSc, B.Com). Responsive layout, mobile menu, program search.

👤 Phase 2 — Done

Student records — add a student and search students by name or program. Records sync in realtime with the mobile app (Firebase, demo only); an offline copy is kept in this browser.

✅ Phase 3 — Done

Attendance — pick a program and a date, mark students present or absent, and see the day's summary. Synced in realtime with the mobile app (Firebase, demo).

💳 Phase 4 — Done

Fees record — see paid and pending fees, mark a fee as paid, and view the collection summary. Synced in realtime with the mobile app (Firebase, demo).

📊 Phase 5 — Done

Result report — marks and grades for each program, with a class summary (average, top student, pass count).

🎓 Who built it

Tasleem Bibi, final-year BSCS student, Begum Nusrat Bhutto Women University, Sukkur. PITP Certified Web Developer & Data Scientist. She studied ADS Science at this college.
